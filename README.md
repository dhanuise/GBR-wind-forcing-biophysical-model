# GBR-wind-forcing-biophysical-model
This repository contains the code and supporting data used in the manuscript entitled 'Sensitivity of biophysical dispersal models to wind forcing in the Great Barrier Reef'.

Hydrodynamic simulations were performed using the SLIM hydrodynamic model forced with three different wind products (ERA5, BARRA2-C and ACCESS). A particle-tracker model was subsequently used to simulate seagrass dispersal and generate connectivity matrices. The scripts provided here reproduce the connectivity analysis, statistical analyses and figures presented in the manuscript.

The complete hydrodynamic model outputs are not included because each simulation is approximately 750 GB. Processed outputs required to reproduce the analyses presented in the manuscript are provided.
